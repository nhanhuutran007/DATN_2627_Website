# Training

Pipeline huấn luyện sẽ được đặt tại đây và chạy ngoài request/response path. Pipeline cần lưu chung preprocessing với estimator, đồng thời xuất model metadata và báo cáo đánh giá.

Chỉ thêm thư viện ML khi bắt đầu triển khai pipeline, và khóa đúng phiên bản vào lockfile hoặc requirements đã pin sau khi đánh giá mô hình.
